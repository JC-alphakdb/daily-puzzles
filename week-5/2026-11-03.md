# q Daily Quiz — 2026-11-03 (Tuesday)

Theme: nested lists. 10 harder challenges built around a dictionary mapping student names to their list of test scores — a small, uneven class record (not every student has taken the same number of tests). Write each answer as a function that takes `grades` (or the stated arguments) and returns the result. Most solutions still fit in a handful of lines.

---

Assume this dictionary for every question today:

	q)grades:`Alice`Bob`Carol!(85 90 78 92;60 65 70;88 95 91 85 90)
	q)grades

	Bob  | 60 65 70
	Carol| 88 95 91 85 90

Each student maps to the list of scores they got, in the order the tests were taken.
