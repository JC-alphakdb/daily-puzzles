# q Daily Quiz — 2026-11-06 (Friday)

Theme: parsing a clickstream. 10 harder challenges: turn a list of raw web event lines into a structured table, then dig into the funnel. Write each answer as a function that takes the stated arguments and returns the result. Most solutions still fit in a handful of lines.

---

Assume this list of raw event lines for every question today:

	q)logs:("09:01:00 S1 VIEW /home";"09:01:20 S1 VIEW /products";"09:01:45 S1 CLICK /cart";"09:02:10 S1 PURCHASE amount=49.99";"09:01:05 S2 VIEW /home";"09:03:00 S2 VIEW /products";"09:03:30 S2 CLICK /cart";"09:05:00 S3 VIEW /home";"09:05:40 S3 VIEW /products";"09:06:10 S3 CLICK /cart";"09:06:50 S3 PURCHASE amount=120.00";"09:07:00 S4 VIEW /home")

Each line has the shape `<time> <sessionId> <eventType> <detail>` — `detail` is a page path for `VIEW`/`CLICK` events, or `amount=<value>` for `PURCHASE` events.

---
