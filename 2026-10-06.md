# q Daily Quiz — 2026-10-06 (Tuesday)

Theme: strings & words. 15 quick challenges, easy to hard. All solutions fit in 1-3 lines.

---

### 1. String to integer

Parse a string of digits into an integer.

	q)stringToInt "42"
	42

---

### 2. Count consonants

Count how many consonants appear in a string (letters that aren't vowels or spaces).

	q)countConsonants "hello world"
	7

---

### 3. Swap case

Swap the case of every letter in a string.

	q)swapCase "Hello World"
	"hELLO wORLD"

---

### 4. Word lengths

Return the length of each word in a sentence.

	q)wordLengths "the cat sat"
	3 3 3

---

### 5. Longest word length

Return the length of the longest word in a sentence.

	q)longestWordLen "how is the going today"
	5

---

### 6. Average word length

Return the average word length in a sentence.

	q)avgWordLen "the cat sat"
	3

---

### 7. Reverse word order

Reverse the order of the words in a sentence, keeping each word intact.

	q)reverseWordOrder "how are you today"
	"today you are how"

---

### 8. Reverse each word

Reverse the letters within each word, keeping the word order intact.

	q)reverseEachWord "how are you"
	"woh era uoy"

---

### 9. Squeeze spaces

Collapse runs of multiple spaces down to a single space.

	q)squeezeSpaces "a   b  c    d"
	"a b c d"

---

### 10. Is isogram

Check whether a word has no repeating letters.

	q)isIsogram "world"
	1b
	q)isIsogram "hello"
	0b

---

### 11. Count a character

Count how many times a given character appears in a string.

	q)charCount["mississippi";"s"]
	4

---

### 12. Most common word

Find the most frequently occurring word in a sentence.

	q)mostCommonWord "the cat sat on the mat the cat ran"
	"the"

---

### 13. Longest vowel run

Find the length of the longest run of consecutive vowels in a word.

	q)longestVowelRun "sequoia"
	4

---

### 14. Digital root

Repeatedly sum a number's digits until a single digit remains.

	q)digitalRoot 9875
	2

---

### 15. Collatz length

Return the number of steps in the Collatz sequence from n down to 1 (inclusive of both ends).

	q)collatzLen 27
	112
