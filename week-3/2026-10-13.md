# q Daily Quiz — 2026-10-13 (Tuesday)

Theme: strings & words. 15 quick challenges, easy to hard. All solutions fit in 1-3 lines.

---

### 1. Count spaces

Count how many space characters appear in a string.

	q)countSpaces "a b c d"
	3

---

### 2. Is blank

Check whether a string consists entirely of spaces.

	q)isBlank "   "
	1b
	q)isBlank "  a "
	0b

---

### 3. Is upper case

Check whether every letter in a string is upper case.

	q)isUpperCase "HELLO"
	1b
	q)isUpperCase "Hello"
	0b

---

### 4. Is lower case

Check whether every letter in a string is lower case.

	q)isLowerCase "hello"
	1b

---

### 5. Distinct character count

Count how many distinct characters appear in a string.

	q)distinctCharCount "mississippi"
	4

---

### 6. Sum of ASCII codes

Sum the ASCII codes of every character in a string.

	q)sumASCII "AB"
	131

---

### 7. First vowel index

Return the index of the first vowel in a string.

	q)firstVowelIndex "rhythm algebra"
	7

---

### 8. Count unique words

Count how many distinct words appear in a sentence.

	q)countUniqueWords "the cat sat the cat ran"
	4

---

### 9. Count words starting with

Count how many words in a sentence start with a given letter.

	q)countWordsStartingWith["the cat sat on the mat";"t"]
	2

---

### 10. Initials

Return the first letter of each word, joined together.

	q)initials "Alpha Beta Gamma"
	"ABG"

---

### 11. Remove duplicate words

Remove duplicate words from a sentence, keeping the first occurrence of each.

	q)removeDuplicateWords "the cat sat the cat ran"
	"the cat sat ran"

---

### 12. Count palindrome words

Count how many words in a sentence are themselves palindromes.

	q)wordPalindromeCount "wow this is not a racecar level"
	4

---

### 13. Is palindrome phrase

Check whether a phrase is a palindrome, ignoring spaces and case.

	q)isPalindromePhrase "A man a plan a canal Panama"
	1b
	q)isPalindromePhrase "hello world"
	0b

---

### 14. Repeat a string

Repeat a string n times.

	q)stringRepeat["ab";3]
	"ababab"

---

### 15. Letters missing

Return the letters of the alphabet that don't appear anywhere in a string.

	q)lettersMissing "the quick brown fox"
	"adgjlmpsvyz"
