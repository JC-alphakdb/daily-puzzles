# q Daily Quiz — 2026-10-09 (Friday)

Theme: dates, dicts, tables & number theory. 15 quick challenges, easy to hard. All solutions fit in 1-3 lines.

---

### 1. Average of a vector

Return the average of a vector.

	q)avgOf 1 2 3 4 5
	3

---

### 2. Simple interest

Compute simple interest given principal, rate (%) and time.

	q)simpleInterest[1000;5;2]
	100

---

### 3. Is leap year

Check whether a year is a leap year.

	q)isLeapYear 2024
	1b
	q)isLeapYear 1900
	0b
	q)isLeapYear 2000
	1b

---

### 4. Is weekend

Check whether each day-name symbol falls on a weekend.

	q)isWeekend each `Mon`Sat`Sun`Wed
	0110b

---

### 5. Days between dates

Return the number of days between two dates.

	q)daysBetween[2024.01.01;2024.03.15]
	74

### 6. Invert a dictionary

Swap the keys and values of a dictionary.

	q)dictInvert `a`b`c!1 2 3
	1| a
	2| b
	3| c

---

### 7. Keys where

Return the keys of a dictionary whose values are true.

	q)keysWhere `a`b`c!011b

### 8. Sum a column

Write a query that sums the `price` column.

	q)exec sum price from t
	60

### 9. Filter rows

Write a query that returns only the rows where `price` is greater than 15.

	q)select from t where price>15
	sym price
	---------
	b   20
	a   30

### 10. Add a derived column

Write a query that adds a `double` column equal to twice the price.

	q)update double:price*2 from t

	a   30    60
