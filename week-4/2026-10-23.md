# q Daily Quiz — 2026-10-23 (Friday)

Theme: parsing raw logs. 10 harder challenges: turn a list of raw log lines into a structured table, then dig into it.

---

Assume this list of raw log lines for every question today:

	q)logs:("09:12:03 INFO auth User alice logged in";"09:12:47 WARN db Slow query took 1200ms";"09:13:10 ERROR auth Failed login for user bob";"09:14:02 INFO web Served request from 10.0.0.5";"09:14:55 ERROR db Connection timeout";"09:15:30 ERROR auth Failed login for user bob";"09:16:01 INFO auth User carol logged in";"09:16:45 WARN web High memory usage 85%")

Each line has the shape `<time> <level> <module> <free-text message>`.

---

### 1. Parse the logs into a table

Write `parseLine`, then apply it to every line to build `logTbl` with columns `time`, `level`, `module` and `message`.

	q)parseLine:{w:" " vs x; (`time`level`module`message)!((`second$"T"$w 0);`$w 1;`$w 2;" " sv 3_w)}
	q)logTbl:parseLine each logs
	q)logTbl
	time     level module message
	----------------------------------------------------
	09:12:03 INFO  auth   "User alice logged in"
	09:12:47 WARN  db     "Slow query took 1200ms"
	09:13:10 ERROR auth   "Failed login for user bob"
	09:14:02 INFO  web    "Served request from 10.0.0.5"
	09:14:55 ERROR db     "Connection timeout"
	09:15:30 ERROR auth   "Failed login for user bob"
	09:16:01 INFO  auth   "User carol logged in"
	09:16:45 WARN  web    "High memory usage 85%"

### 4. Who failed to log in?

Extract the username from each `ERROR`/`auth` "Failed login" message.

	q)failed:select from logTbl where level=`ERROR, module=`auth
	q)exec `$last each " " vs/:message from failed
	`bob`bob

### 6. Noisiest module

Return the module(s) with the most non-`INFO` (i.e. `WARN`/`ERROR`) entries.

	q)nonInfo:select cnt:count i by module from logTbl where level<>`INFO
	q)exec module from nonInfo where cnt=max cnt
	`auth`db

### 7. Modules with at least one error

	q)exec distinct module from logTbl where level=`ERROR
	`auth`db

### 8. Time between consecutive errors
