# q Daily Quiz — 2026-10-20 (Tuesday)

Theme: nested dictionaries. 10 harder challenges built around a dictionary-of-dictionaries — a small, uneven multi-warehouse stock count. Most solutions still fit in a handful of lines.

---

Assume this dictionary for every question today:

	q)stock:`W1`W2`W3!(`apple`banana`cherry!10 5 20; `apple`banana!8 12; `cherry`date!15 7)
	q)stock
	W1| `apple`banana`cherry!10 5 20
	W2| `apple`banana!8 12
	W3| `cherry`date!15 7

Each warehouse is itself a dictionary mapping item name to quantity on hand — note the warehouses don't all carry the same items.

---

### 1. Total stock per warehouse

Return a dictionary mapping each warehouse to its total quantity across all items.

	q)sum each stock
	W1| 35
	W2| 20
	W3| 22

---

### 2. Warehouse with the most stock

Return the warehouse holding the greatest total quantity.

	q)t:sum each stock
	q)where t=max t
	,`W1

---

### 3. Company-wide quantity per item

Merge the three warehouses' stock, summing quantities where an item appears in more than one warehouse.

	q)exec sum qty by item from ([]item:raze key each stock;qty:raze value each stock)
	item  | qty
	------| ---
	apple | 18
	banana| 17
	cherry| 35
	date  | 7

---

### 4. Items stocked everywhere

Return the items that are stocked in *every* warehouse.

	q)inter/[value key each stock]
	`symbol$()

(There aren't any here — every item is missing from at least one warehouse.)

---

### 5. Items stocked in exactly one warehouse

	q)allItems:raze key each stock
	q)cnts:count each group allItems
	q)where cnts=1
	,`date

---

### 6. Where is an item stocked?

Given an item, return a dictionary mapping each warehouse that carries it to its quantity (skip warehouses that don't have it at all). Try it for `apple`.

	q)r:stock[;`apple]
	q)w:where not null r
	q)w!r w
	W1| 10
	W2| 8

---

### 7. Lowest-stock warehouse for an item

Given an item, return the warehouse holding the *least* of it — only considering warehouses that stock it at all. Try it for `cherry`.

	q)c:stock[;`cherry]
	q)w:where not null c
	q)cc:w!c w
	q)where cc=min cc
	,`W3

---

### 8. How many distinct items, company-wide?

	q)count distinct raze key each stock
	4

### 9. Best-stocked item per warehouse

Return a dictionary mapping each warehouse to the item it holds the most of.

	q){where x=max x} each stock
	W1| cherry
	W2| banana
	W3| cherry

### 10. Items that need restocking

Return the items whose company-wide total quantity is below 20, as a dictionary sorted ascending by quantity.

	q)tot:exec sum qty by item from ([]item:raze key each stock;qty:raze value each stock)
	q)ks:where tot<20
	q)asc ks!tot ks
	date  | 7
	banana| 17
	apple | 18
