# q Daily Quiz — 2026-11-10 (Tuesday)

Theme: a social graph. 10 harder challenges built around a dictionary mapping each user to the list of users they follow — an adjacency list. It starts with counting and inverting, then moves on to traversal with `over`/`scan`. Write each answer as a function that takes `follows` (or the stated arguments) and returns the result. Most solutions still fit in a handful of lines.

---

Assume this dictionary for every question today:

	q)follows:`ann`bob`cat`dan`eve`fay`gus!(`bob`cat;enlist`cat;`ann`dan;enlist`eve;enlist`dan;`ann`cat`eve;`symbol$())
	q)follows
	ann| `bob`cat
	bob| ,`cat
	cat| `ann`dan
	dan| ,`eve
	eve| ,`dan
	fay| `ann`cat`eve
	gus| `symbol$()

Each key follows every user in its list. Follows are one-directional: `ann` follows `bob`, but `bob` doesn't follow `ann` back. `gus` follows nobody.

### 2. Invert the graph

For every user, the list of users who follow them. Every user must appear, even with no followers.

	q)followers follows
	ann| `cat`fay
	bob| ,`ann
	cat| `ann`bob`fay
	dan| `cat`eve
	eve| `dan`fay
	fay| `symbol$()
	gus| `symbol$()

### 3. Most followed

The user(s) with the most followers.

	q)mostFollowed follows

### 7. Friends of friends

Given a user, return the users exactly two hops away — followed by someone they follow — excluding the user themselves and anyone they already follow directly.

	q)friendsOfFriends[follows;`bob]

### 8. Everyone reachable

	q)reachable[follows;`bob]

	q)reachable[follows;`gus]
	`symbol$()
