Theme: parsing a support-ticket log. 10 harder challenges: turn pipe-delimited raw ticket events into a table, then measure response times and dig through the message text. Write each answer as a function that takes the stated arguments and returns the result. Most solutions still fit in a handful of lines.

Each line has the shape `<time>|<ticketId>|<event>|<who>|<text>`. `event` is `OPEN` (customer raises the ticket), `AGENT` (support agent replies), `CUST` (customer follow-up) or `CLOSE` (agent closes it). `who` is the customer for `OPEN`/`CUST` and the agent for `AGENT`/`CLOSE`.

### 1. Parse the log into a table

Write `parseTickets`, mapping each raw line to a row with columns `time` (minute), `ticket`, `event`, `who` (symbols) and `text` (string).

	q)tk:parseTickets msgs
	q)tk
	time  ticket event who   text                                         
	----------------------------------------------------------------------
	08:02 T101   OPEN  alice "Cannot log in - reset email never arrives"

	08:15 T101   AGENT zoe   "Hi Alice, can you check your spam folder?"
